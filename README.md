# KI-Fußballkamera – 4P-Business-Simulator

Interaktiver Simulator für ein Geschäftsmodell mit KI-gestützter Fußballkamera.

## Funktionen

- 15 Variablen nach den 4 Ps: Product, Price, Place und Promotion
- Schieberegler für 1 bis 5 Geschäftsjahre
- Verkaufte Kameras je Jahr in Einerschritten (auch direkte Zahleneingabe)
- Berechnung von Nettoumsatz, Kosten, Gewinn oder Verlust
- Diagramme, Break-even-Anzeige und CSV-Export
- Speicherung der Werte lokal im Browser

## GitHub Pages aktivieren

1. **Settings → Pages** öffnen.
2. Bei *Build and deployment* als Source **Deploy from a branch** wählen.
3. Branch **main**, Ordner **/(root)** wählen.
4. **Save** anklicken.

Die Adresse wird anschließend https://lucakroll7-a11y.github.io/ki-fussballkamera-simulator/ sein, sobald die Veröffentlichung durch GitHub Pages abgeschlossen ist.

## Lokal ausführen

`index.html` direkt im Browser öffnen. Keine Installation oder Internetverbindung erforderlich.

## Annahmen

Planungs- und Modellwerte, keine geprüften Angebote oder Absatzprognosen. Umsatzsteuer vereinfacht mit 20 %; Fixkosten jährlich 120.000 €; Garantie 5 % der Kameraherstellung; Zahlungsgebühren 2,5 % der Bruttoerlöse; neue Abos im Kaufjahr durchschnittlich sechs bezahlte Monate und verlängerte Abos zwölf. Nicht berücksichtigt: Gewinnsteuern, Inflation, Zinsen, Abschreibungen und Lagerfinanzierung.
